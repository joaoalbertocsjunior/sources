# Roadmap

## Q1 2027

- Publish to crates.io
- Add MCP adapter (`mcp_server` kind via JSON-RPC 2.0)
- Basic documentation site (GitHub Pages)

## Q2 2027

- Standalone binary release (Linux x86_64, macOS arm64, Windows x86_64)
- Usage examples for Go and Node clients consuming the binary over HTTP
- GitHub Actions CI (build + test on all three platforms)

## Q3 2027

- First verified external adopter
- Async sync support (non-blocking registry operations)
- Adapter health/status reporting via HTTP control plane

---

Items are intentionally scoped to what two maintainers can ship. Nothing here is speculative.
